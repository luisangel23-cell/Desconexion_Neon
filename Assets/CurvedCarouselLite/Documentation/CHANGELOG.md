# Changelog — Curved Carousel Menu Lite (FREE)

CodeStart-AI

## 1.0.0
- First release.
- Arc layout: visible slots, start index, spacing, curve, direction, rotation per slot, scale and opacity falloff, fit to width.
- Center item: center scale, center opacity, fading highlight, small selection pop.
- Cards: image, title, subtitle, item ID, Disabled (interactable) state; included card prefab; Create Card Prefab tool.
- Input: mouse drag, touch swipe, Previous/Next buttons, click to focus/select, arrow keys (A/D) and Enter/Space via the Input System.
- Smooth snapping and looping; Auto Center.
- Events: On Center Changed, On Item Selected.
- API: NextItem, PreviousItem, GoToItem, SelectCurrentItem, GetCurrentIndex, GetItemCount, GetItem, GetCurrentItem, AddItem, SetItems, ClearItems, Refresh, Rebuild.
- Runtime EventSystem creation with a valid, self-contained Input System UI action asset.
- Beginner-friendly Inspector, Scene-view slot preview, demo scene with original artwork, Generate Demo tool.
